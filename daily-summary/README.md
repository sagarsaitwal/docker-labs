condensed narrative of the same journey; these files carry the full detail -
every command, every mistake, and the reasoning behind each fix.

One file per day. Days 0-4 are written up; days 5-14 are prepared templates
with the plan, the commands to practise, and a drill — fill in the bottom four

## Structure of each file

```text
1. Plan            what this session is for
2. Commands        what to practise
3. Drill           do it from memory
4. What I did      fill in
5. Mistakes made   fill in - root cause, not just the symptom
6. What I learned  fill in
7. Keep in mind    fill in - the rules worth carrying forward
```

## How to use it

Write section 5 honestly. The mistakes are what you will actually remember, and
they are the raw material for the public `JOURNAL.md` entries that make the repo
credible.
